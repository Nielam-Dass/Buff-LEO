# Buff LEO 💪🦁
This is a Chrome extension to expand features in Tutor.com's (TDC) LEO platform.

## ⚠️ Disclaimer
This is an individual project and NOT managed by TDC. The software may produce unexpected behavior and negatively impact user experience of the LEO platform. If this happens, please disable the extension.

## How to install

### Chrome Web Store
1. Find the [Buff LEO extension on CWS](https://chromewebstore.google.com/detail/buff-leo/mgpfpllkcckneabmdknldaldimencgma).
2. Click the Add button and confirm installation.

### Developer mode
If you want to install pre-release versions, you need to use developer mode.
1. Go to the [Releases](https://github.com/Nielam-Dass/Buff-LEO/releases) page and find the assets for the most recent version.
2. Download the zip file called `buff-leo-vX.X.X.zip`, where `vX.X.X` represents the version number.
3. Extract the zip folder.
4. Open Chrome (or any Chromium-based browser), and navigate to the *Manage extensions* page.
5. Enable *Developer mode* and click the *Load unpacked* button.
6. Select the folder you just unzipped.
